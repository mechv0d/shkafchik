## 1. Требования к приложению

1. Мобильное приложение для управления личным гардеробом — добавление, просмотр, редактирование и удаление вещей.
2. Поддержка тегов и поиска по тегам/названию вещи.
3. Возможность прикреплять фото к предметам.
4. Сохранение данных локально с возможностью последующей синхронизации (опция).
5. Приложение должно работать в среде React Native (Expo).

## 2. Используемые технологии

Подробно стек технологий описан в файле `!doc/TECH_STACK.md`. Ключевые пункты:

- Язык: TypeScript
- Платформа: React Native (Expo)
- Управление серверным состоянием: React Query
- Локальное хранилище: AsyncStorage
- Инструменты разработки: Git, Expo CLI, ESLint, Prettier, Husky, lint-staged

(Детали и обоснования см. `!doc/TECH_STACK.md`)

## 3. Архитектура приложения

Выбран подход: Feature-Sliced Design (FSD).

Краткое описание:

- Логическое разбиение на слои: `app`, `pages`, `widgets`, `features`, `entities`, `shared`, `hooks`, `storage`, `types`.
- Ответственность слоев и правила импорта — см. `ARCHITECTURE.md` в корне проекта.

Схема взаимодействия (текст):

- Пользовательский интерфейс (страницы + виджеты) взаимодействует с фичами (UI + model).
- Фичи используют сущности (бизнес-модели) и общий `shared` код (API, UI-компоненты, утилиты).
- React Query отвечает за синхронизацию данных и кеширование; AsyncStorage — за локальное хранение.

## 4. Описание стартового проекта

1. Инициализация:
   - Стартовый проект создан с помощью `expo init` (TypeScript шаблон).
   - Точка входа: `App.tsx` в папке `src/app/`.
2. Базовая структура каталогов (реализована по FSD):
   - `src/app/`, `src/pages/`, `src/widgets/`, `src/features/`, `src/entities/`, `src/shared/`, `src/hooks/`, `src/storage/`, `src/types/`.
3. Реализовано/заготовлено:
   - Корневой layout и провайдеры (React Query, Context).
   - Базовые UI-компоненты в `shared/ui/` (Button, EmptyState, ItemCard).
   - Сервис хранения данных `shared/api/wardrobeApi.ts` (заглушки, чтение/запись в `storage`).
4. Сборка и запуск:
   - `npm install` или `yarn`
   - `expo start` — запуск в эмуляторе/на устройстве
