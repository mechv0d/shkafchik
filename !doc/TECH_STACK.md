# Технологический стек проекта "Шкафчик"

## Краткое резюме

Проект реализуется как мобильное приложение на базе React Native с использованием Expo и TypeScript. Выбор инструментов направлен на быструю разработку, хорошие интегрированные инструменты разработки и простоту распространения (Expo).

## Язык программирования

- **TypeScript** — явная типизация повышает надёжность кода, улучшает автодополнение и удобство рефакторинга.

## Платформа / среда выполнения

- **React Native (Expo)** — кроссплатформенная мобильная разработка (iOS, Android) с быстрым циклом разработки и готовыми сервисами Expo.

## Фреймворки и библиотеки (основные)

- **React** — компонентная модель UI.
- **React Native** — рендер нативного интерфейса.
- **Expo** — инструментальная цепочка и runtime для упрощённого разворачивания.
- **React Navigation** — маршрутизация и навигация между экранами.
- **React Query** — управление серверным состоянием, кэширование и синхронизация.
- **AsyncStorage** — локальное хранилище данных на устройстве.
- **Axios / fetch** — HTTP-клиент (если потребуется интеграция с внешним API).

## Инструменты разработки и сборки

- **Git** — система контроля версий.
- **GitHub / GitLab** — удалённый репозиторий.
- **Expo CLI** — запуск, сборка и отладка приложения.
- **Metro** — бандлер React Native (через Expo).
- **EAS (Expo Application Services)** — опциональная служба для сборки нативных бинарников.

## Тестирование

- **Jest** — юнит-тесты.
- **React Native Testing Library** — тестирование компонентов.
- E2E (опционально): **Detox** или **Appium** — для e2e тестирования на устройствах/эмуляторах.

## Статический анализ и форматирование

- **ESLint** — линтинг кода.
- **Prettier** — форматирование.
- **Husky + lint-staged** — pre-commit хуки для проверки/форматирования коммитов.

## CI/CD

- **GitHub Actions** (рекомендуется) — автоматический запуск линтеров, тестов и сборок.
- В случае использования EAS — автоматические сборки бинов и публикация.

## Управление состоянием

- Клиентское состояние: **React Context API** (для UI/настроек).
- Серверное/удалённое состояние и кеш: **React Query**.

## Слои и архитектура

- Архитектурный подход: **Feature-Sliced Design (FSD)** — подробности в `ARCHITECTURE.md`.

## Версионные рекомендации (пример)

- Node.js: >=16
- Expo CLI: последняя стабильная версия совместимая с SDK проекта
- TypeScript: ^4.x
- React Native: соответствующая версии Expo SDK

## Ограничения и правила

- Использование технологий за пределами зафиксированного стека допускается только при обязательном обосновании и согласовании.
- Любые новые внешние зависимости должны проходить проверку на размер, безопасность и необходимость.
