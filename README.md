# Шкафчик - Умное управление гардеробом

## Описание проекта

**"Шкафчик"** - мобильное приложение для каталогизации и управления личным гардеробом. Приложение позволяет пользователям систематизировать свои вещи, отслеживать их использование, планировать образы и эффективно управлять пространством хранения.

Проект разработан в рамках лабораторных работ по курсу мобильной разработки и представляет полнофункциональное решение для организации гардероба с современным интерфейсом и продуманной архитектурой.

## Цели и задачи

### Основные цели:

- Создать удобный инструмент для управления личным гардеробом
- Обеспечить быстрый доступ к информации о вещах
- Автоматизировать процесс каталогизации одежды и аксессуаров

### Задачи проекта:

- Реализовать полный CRUD-функционал для управления вещами
- Создать иерархическую систему категорий с подкатегориями
- Разработать систему тегов с цветовой кодировкой
- Реализовать капсулы (коллекции) для тематической организации
- Обеспечить мощный поиск и фильтрацию
- Создать интуитивный интерфейс на мобильных устройствах
- Реализовать работу с изображениями (камера/галерея)
- Обеспечить экспорт и обмен данными
- Создать надежную систему хранения данных
- Реализовать обработку ошибок и крайних случаев

## Архитектура приложения

### Структурная архитектура:

```
┌─────────────────────────────────────────┐
│              PRESENTATION               │
│         (React Components)              │
├─────────────────────────────────────────┤
│              BUSINESS LOGIC             │
│         (Custom Hooks & Utils)          │
├─────────────────────────────────────────┤
│               DATA ACCESS               │
│            (DAO Pattern)                │
├─────────────────────────────────────────┤
│               DATABASE                  │
│              (SQLite)                   │
└─────────────────────────────────────────┘
```

### Модульная структура:

```
shkafchik/
├── app/                    # Экраны приложения (Expo Router)
│   ├── (tabs)/            # Основные табы навигации
│   │   ├── items.tsx      # Главная страница с вещами
│   │   ├── search.tsx     # Поиск и фильтрация
│   │   ├── capsules.tsx   # Управление капсулами
│   │   └── stats.tsx      # Статистика и аналитика
│   ├── add-item/          # Мастер добавления вещи
│   ├── edit-item/         # Редактирование вещи
│   ├── item/[id]/         # Детальная карточка вещи
│   └── capsules/          # Управление капсулами
├── components/            # Переиспользуемые UI-компоненты
│   ├── ui/               # Базовые UI-элементы
│   ├── ItemsGrid.tsx     # Сетка вещей
│   ├── CapsulesGrid.tsx  # Сетка капсул
│   └── themed-*.tsx      # Тематизированные компоненты
├── src/
│   ├── api/              # Слой доступа к данным
│   │   └── database.ts   # DAO классы и инициализация БД
│   ├── models.ts         # TypeScript модели данных
│   └── imageProcessor.ts # Обработка изображений
├── styles/               # Стили и темы
├── constants/            # Константы приложения
└── utils/               # Вспомогательные функции
```

### Архитектурные паттерны:

- **DAO (Data Access Object)** - для работы с базой данных
- **Component-based architecture** - модульные компоненты
- **File-based routing** - интуитивная навигация
- **Custom hooks** - управление состоянием и бизнес-логикой

### База данных:

**Реляционная модель** со следующими основными таблицами:

- `Items` - основные вещи с атрибутами
- `Categories` - иерархические категории
- `Tags` - теги с цветовой кодировкой
- `Capsules` - коллекции вещей
- `Images` - множественные изображения
- `Attributes` - гибкие атрибуты вещей
- `Settings` - настройки приложения

## Инструкция по запуску

### Системные требования:

- **Node.js** версии 16 или выше
- **npm** или **yarn** для управления зависимостями
- **Expo CLI** для запуска приложения
- **iOS Simulator** / **Android Emulator** или физическое устройство

### Пошаговая инструкция:

#### 1. Клонирование репозитория

```bash
git clone https://github.com/mechv0d/shkafchik.git
cd shkafchik
```

#### 2. Установка зависимостей

```bash
npm install
# или
yarn install
```

#### 3. Запуск development сервера

```bash
npm start
# или
yarn start
```

#### 4. Запуск на конкретной платформе

```bash
# Для iOS
npm run ios

# Для Android
npm run android

# Для Web
npm run web
```

#### 5. Дополнительные команды

```bash
# Проверка кода
npm run lint

# Сброс проекта
npm run reset-project
```

### Возможные проблемы и решения:

#### Проблема: "Metro bundler не запускается"

**Решение:**

```bash
npx expo start --clear
```

#### Проблема: "Ошибка подключения к устройству"

**Решение:**

1. Убедитесь, что Expo Go установлен на устройстве
2. Проверьте подключение к той же сети Wi-Fi
3. Используйте QR-код из терминала

#### Проблема: "База данных не инициализируется"

**Решение:**

1. Перезапустите приложение
2. Проверьте права доступа к хранилищу
3. Очистите кэш приложения

## Экраны приложения

### Главная (Вещи)

- Сетка всех вещей с изображениями
- Быстрый поиск и фильтрация
- Сортировка по различным параметрам
- Быстрые фильтры (избранное, в корзине, купленные)

### Поиск

- Расширенный поиск по названию
- Фильтры по категориям и атрибутам
- Сортировка по цене, дате, названию
- Результаты в реальном времени

### Добавление вещи

Пошаговый мастер:

1. **Фото** - камера или галерея
2. **Название** - основная информация
3. **Категория** - иерархический выбор
4. **Атрибуты** - цена, описание, дата покупки
5. **Теги** - цветовая кодировка

### Детальная карточка

- Полная информация о вещи
- Галерея изображений
- Описание и характеристики
- Теги и категория с навигацией
- Действия (редактировать, удалить, поделиться)

### Капсулы

- Управление коллекциями вещей
- Временные и постоянные капсулы
- Отслеживание статуса упаковки
- Интеграция с календарем

### Статистика

- Аналитика использования гардероба
- Статистика по категориям
- Динамика пополнения
